## 2026-05-01 - Skip to Main Content Link\n**Learning:** Implementing a visually hidden 'Skip to main content' link is an easy accessibility win that greatly improves keyboard navigation. Using Tailwind's `sr-only focus:not-sr-only` classes allows the link to remain hidden until focused. It's crucial to also add `tabindex="-1"` and `focus:outline-none` to the target main content area so it can properly receive programmatic focus without showing an unsightly focus ring on click.\n**Action:** Apply this pattern to layout files in future projects to ensure keyboard users can bypass repetitive header navigation.
