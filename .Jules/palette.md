## 2024-04-22 - Skip to content links and main nav landmarks
**Learning:** Found missing skip-to-content functionality and lacking aria-label on primary navigation which are key features for proper screen reader and keyboard accessibility, especially on layouts with large sticky headers.
**Action:** Always verify keyboard accessibility of layouts specifically ensuring a skip-to-content visually hidden link exists (e.g. `sr-only focus:not-sr-only`) targeting the main wrapper, and ensure `nav` tags have distinctive aria labels to be read out well.

## 2024-05-18 - Multiple focus indicator styles and programmatic focus handling
**Learning:** Found that applying focus rings specifically with `focus-visible` ensures keyboard users get clear visual feedback without distracting mouse users. Also confirmed that a "skip to content" link target (like `<main>`) must explicitly have `tabindex="-1"` and `focus:outline-none` to properly receive and handle programmatic focus from screen readers without showing an unwanted default browser outline. Finally, adding `aria-hidden="true"` to decorative `<svg>` elements inside anchor tags prevents redundant or confusing screen reader announcements.
**Action:** When implementing focus states globally, use `focus-visible` along with theme-aware colors (e.g., `focus-visible:ring-ink focus-visible:ring-offset-beige`). Always ensure skip link targets are programmatically focusable with `tabindex="-1"`. Hide decorative SVG icons within interactive elements using `aria-hidden="true"`.
