## 2024-03-21 - Keyboard Navigation and Focus Styles
**Learning:** For Astro projects relying on Tailwind, the default focus outline can be insufficient or clash with the design system. Additionally, keyboard and screen reader accessibility is often missed in the base layout without a "Skip to content" link.
**Action:** Implemented a global `*:focus-visible` CSS rule in `src/styles/global.css` using the existing design system palette (`copper` and `beige`) to provide high-contrast keyboard focus indicators. Implemented a visually hidden "Skip to main content" link at the top of `BaseLayout.astro` that becomes visible on focus, targeting an ID on the main content area, which itself receives a `tabindex="-1"` and `focus:outline-none` so it can programmatically receive focus without a visual outline. This pattern should be standard for all base layouts.
